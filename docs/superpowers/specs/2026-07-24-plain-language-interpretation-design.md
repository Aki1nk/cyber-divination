# 卦象解读白话辅助设计

**日期：** 2026-07-24

**状态：** 待用户审阅

**范围：** 本地解读文本与其测试；不改变任何起卦、排盘或存储规则。

## 1. 目标

让用户在不熟悉《易经》术语时，也能读懂每一段卦象解读的实际含义。结果页继续保留可复核的传统术语，并在术语后紧接简短的白话括注和可执行提醒。

示例：

> 体克用（你目前仍有主动权）：先把能决定的事做扎实，再处理外部变化。

## 2. 不在范围内

- 不修改本卦、互卦、变卦、动爻、体用、五行旺衰的计算。
- 不修改经典原文、计算日志、历史记录或风险识别逻辑。
- 不引入账号、网络请求、AI 模型、个性化推断或新的设置项。
- 不将传统文化参考包装为医疗、法律、投资或重大人生决定的确定性结论。

## 3. 内容结构

结果页既有的五个解读区块保持不变：局势摘要、有利因素、阻碍因素、时机倾向、行动建议。每段按以下顺序生成：

1. **传统判断：** 保留体用关系、旺衰、动爻或风险边界等依据。
2. **白话括注：** 用一句日常语言解释该术语在当前规则中的含义。
3. **行动提醒：** 给出保守、可逆、可通过现实反馈调整的下一步。

其中“局势摘要”可同时呈现本卦、互卦、变卦名称，但不能把卦名解释为保证性的预测。

## 4. 文案规则

### 4.1 体用关系

| 传统术语 | 白话括注 | 行动语气 |
| --- | --- | --- |
| 体克用 | 你目前仍有主动权 | 先处理自己能决定的部分，再安排外部协作。 |
| 用克体 | 外部压力或条件更强 | 放慢节奏，补齐信息并预留协商空间。 |
| 体生用 | 你正在投入较多精力支持外部事项 | 设好投入上限，避免一味消耗。 |
| 用生体 | 外部条件能提供帮助 | 主动借助资源，但仍核实关键前提。 |
| 体用比和 | 内外条件较容易配合 | 保持节奏，优先推进已达成共识的事项。 |

### 4.2 五行旺衰

旺衰描述使用“当前条件较有利”或“当前条件较需谨慎”等白话补充，不将其表示为运势、命运或不可改变的结果。它只用于提醒用户评估可用资源、时间和准备程度。

### 4.3 动爻与时机

动爻继续作为阶段变化提示。白话说明固定包含“这是阶段提醒，不是具体日期或结果保证”，避免用户把它当作择日或预言。

### 4.4 风险边界

涉及医疗、投资、法律、紧急危险或自伤风险时，风险提示优先于普通行动建议。文案继续要求用户寻求合格专业人士、紧急服务或可信任的人，不用卦象替代现实判断。

## 5. 呈现与可访问性

- 继续使用文本段落，不新增图标、颜色含义或仅靠视觉传达的信息。
- 传统术语和括注在同一段落中呈现，读屏顺序自然连续。
- 经典原文、规则推演与现代白话解读继续分层，避免将应用编写的文字误认为古籍原文。

## 6. 实现边界

仅调整 `src/data/interpretation-rules.js` 与 `src/domain/interpretation.js` 中的解读文本/模板，并按现有测试风格更新 `test/domain/interpretation.test.js`。如结果页面只渲染既有 `sections` 数据，则不改动 UI 结构。

## 7. 验收标准

1. 五种体用关系均同时具有术语、白话括注和保守行动提醒。
2. 旺衰、动爻和风险内容均使用非绝对化表达。
3. 所有白话文案避免“必然、一定、保证、注定、稳赚、治愈”等确定性或误导性措辞。
4. 解读的 `reasonKeys`、风险优先级和卦象计算结果保持不变。
5. 现有自动化测试全部通过，并新增/更新测试覆盖上述文本契约。
