# 后台占问记录用户标注设计

## 目标

后台“云端占问记录”的列表和完整详情均明确标注占问所属用户，管理员无需依赖设备编号区分不同用户。

## 展示规则

- 用户设置昵称：`昵称（完整手机号）`
- 用户未设置昵称：`未设置昵称（完整手机号）`
- 历史记录没有 `user_id` 或关联用户不存在：`旧记录（未关联用户）`

完整手机号仅出现在管理员认证后的后台，不进入普通用户接口或公开页面。

## 数据方案

在后台占问查询中使用 `readings LEFT JOIN users`：

- 列表查询返回 `user_nickname` 和 `user_phone`。
- 详情查询返回相同的用户字段。
- 使用 `LEFT JOIN` 保留所有历史占问记录。
- 不新增数据库字段，不需要执行 D1 迁移。
- 用户修改昵称或手机号后，后台占问记录立即显示最新账户资料。

## 界面方案

- 占问列表新增“用户”列。
- 完整占问详情新增“占问用户”信息。
- 用户字段统一通过一个转义安全的格式化函数生成，避免列表和详情规则不一致。
- 不修改用户端登录、起卦、结果和账户页面。

## 接口兼容性

- 后台 API 仅新增响应字段，不删除或重命名现有字段。
- 现有筛选、分页、详情和删除流程保持不变。
- 历史记录和旧版数据继续可查看。

## 测试与验收

1. 仓库列表查询包含 `LEFT JOIN users`，并返回用户昵称和手机号。
2. 仓库详情查询包含相同关联字段。
3. 列表按三种展示规则正确标注用户。
4. 详情按相同规则正确标注用户。
5. 用户提供的昵称、手机号和问题内容均进行 HTML 转义。
6. 完整测试套件和构建命令通过。
7. Cloudflare Preview 通过后合并并验证生产后台页面。

## 非目标

- 不按用户名扩展占问搜索条件。
- 不复制用户名快照到占问记录。
- 不改变设备编号、数据保留期限或用户备注功能。
