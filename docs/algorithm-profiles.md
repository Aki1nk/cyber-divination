# 算法档案

所有档案均为具名、版本化、确定性的本地规则。记录保存 `algorithm.id`、`algorithm.version`、原始输入、不可变快照和中间计算日志，后续设置变化不会改写既有卦录。

## 通用规则

- 八卦数：乾 1、兑 2、离 3、震 4、巽 5、坎 6、艮 7、坤 8。
- 取八卦：`((n - 1) mod 8) + 1`，余数为零时返回 8。
- 取动爻：`((n - 1) mod 6) + 1`，余数为零时返回 6。
- 报数使用 `BigInt` 精确运算，不先转换为 JavaScript `Number`。
- 六爻 ID 自下而上排列，阳爻为 `1`、阴爻为 `0`。
- 动爻在下卦时，下卦为用、上卦为体；动爻在上卦时，上卦为用、下卦为体。
- 互卦取本卦二三四爻为下卦、三四五爻为上卦。

## `meihua-time-classic-v1`

传统时间起卦档案：

```text
上卦总数 = 年支数 + 农历月 + 农历日
下卦总数 = 上卦总数 + 时支数
上卦 = 上卦总数取 8
下卦 = 下卦总数取 8
动爻 = 下卦总数取 6
```

### 时间口径

- 历法：固定版本 `lunar-javascript@1.7.7`。
- 年界：默认农历新年，可显式选择立春。
- 子时：23:00–23:59 必须显式选择午夜换日或早子时换日，禁止静默推断。
- 闰月：保留闰月标记，取数使用月份绝对值。
- 真太阳时：可选。经度修正为 `4 × (经度 - 时区中央经线)` 分钟，并叠加均时差近似；记录修正分钟数、经度和城市标签。

## `number-pair-v1`

```text
上卦 = 第一整数取 8
下卦 = 第二整数取 8
动爻 = (第一整数 + 第二整数) 取 6
```

双数档案不得混用三数档案的第三数动爻规则。

## `number-triple-v1`

```text
上卦 = 第一整数取 8
下卦 = 第二整数取 8
动爻 = 第三整数取 6
```

第三数只决定动爻，不参与上下卦合数。

## `digital-symbol-v1`

现代数字取象档案，不宣称为古籍原法。调用浏览器 `crypto.getRandomValues`，通过拒绝采样避免模偏差，分别生成：

```text
上卦：1–8
下卦：1–8
动爻：1–6
```

每次起卦恰好消费三项安全随机值。问题指纹的 24 小时重复保护仍然生效。

## `external-object-direction-v1`

用户先依据固定的“万物类象 v1”确认物象卦数和方位卦数：

```text
上卦 = 已确认物象卦数
下卦 = 已确认方位卦数
动爻 = (所见数量 + 方位卦数 + 时支数) 取 6
```

未勾选人工确认时不得起卦。物象关键词只提供映射辅助，不自动识别照片、声音或现实环境。

## 五行旺衰与解释

- 五行关系始终从体卦视角表达：同类、体生用、用生体、体克用、用克体。
- 旺衰档案：`four-seasons-earth-months-v1`；木旺春、火旺夏、金旺秋、水旺冬，土旺四季月（三、六、九、十二月）。
- 解释档案：`local-deterministic-v1`；固定输出局势摘要、有利因素、阻碍因素、时机倾向、行动建议。
- 每段解释携带 `reasonKeys`，经典原文、确定性推理和现代释义分层展示。
- 解释禁用确定性保证、诊断、死亡时间、交易指令等措辞。
