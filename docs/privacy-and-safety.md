# 隐私与安全边界

## 本地优先

- 应用没有账号系统、后端 API、云数据库、遥测或广告 SDK。
- 问题、背景、输入、算法档案、计算快照、卦象、解释和设置只写入当前浏览器的 `localStorage`。
- 根键为 `cyber-divination:v1`，结构带 `schemaVersion`。损坏 JSON 会先复制到带时间戳的本地恢复键，再恢复空仓库。
- 问题指纹在本机使用 SHA-256 生成，不上传原文或摘要。
- 首版不提供导出与云同步，避免用户误以为数据已备份。

## 位置权限

- 只有用户在时间起卦页主动点击“使用当前位置”时才调用浏览器定位 API。
- 应用只读取本次计算需要的经度，不持续监听位置。
- 记录只保存经度和用户选择的城市标签，不保存位置轨迹、精确地址或后台定位状态。
- 用户可以不授权，改用民用时间或手动输入经度。

## 清除数据

设置页显示本机卦录数量。点击“清除全部卦录”后必须经过原生确认对话框；取消、关闭或按 Escape 均不删除。确认清除只移除卦录，保留设置。

浏览器自身的“清除站点数据”也会删除全部本地内容，包括设置和 Service Worker 缓存。

## 高风险内容

风险分类使用明确词组表，覆盖：

- 医疗、药物、诊断、手术与怀孕；
- 生死、寿命与自伤；
- 诉讼、犯罪与规避执法；
- 股票、基金、期货、加密资产、借贷和大额财务。

高风险问题仍可生成文化性排盘，避免隐瞒用户输入或伪造结果，但必须显示现实边界：

- 不替代医生、律师、持牌财务专业人员或司法程序；
- 不预测死亡时间、不判断疾病能否治愈、不保证关系或事业结果；
- 不提供具体买卖、加杠杆、借贷或投入全部积蓄的指令；
- 不协助实施、掩盖或规避违法犯罪行为。

自伤相关问题标记为 `urgent`，优先提示立即联系当地急救服务、危机热线或可信任的人陪伴，再允许用户展开文化性排盘。

## 文化体验声明

梅花易数与《周易》内容在本应用中用于传统文化学习、结构化反思与娱乐体验。排盘不是可验证的因果预测工具；用户应以现实证据、专业意见、个人价值和可逆行动作为决策基础。

同一内容已通过应用内 `#/privacy` 页面向最终用户展示，并可从设置页直接进入。生产构建还通过根目录 `_headers` 收敛脚本、样式、连接、定位和嵌入权限。
